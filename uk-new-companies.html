Input fields

FieldTypeMeaning
incorporatedFromstringEarliest incorporation date, YYYY-MM-DD, e.g. "2026-11-01". Empty = the same day as incorporatedTo (so both empty = yesterday, UTC).
incorporatedTostringLatest incorporation date (inclusive), YYYY-MM-DD, e.g. "2026-11-04". Empty = yesterday (UTC), or incorporatedFrom if that is later.
sicCodesarrayUK SIC 2007 code prefixes (Companies House condensed list); a prefix matches every code below it, e.g. ["62"] = IT / software, "6201" = software development, "56101" = licensed restaurants, "68" = real estate. A company matches if any of its SIC codes matches. Empty = all sectors.
locationstringRegistered office location as free text, passed to Companies House's location filter: a town, county or postcode (area), e.g. "London", "Manchester" or "EC1". Empty = all of the UK.
companyTypesarrayCompanies House company types, e.g. ["ltd"] (private limited), "plc", "llp", "private-limited-guarant-nsc" (company limited by guarantee), "limited-partnership". Default ["ltd", "plc", "llp"]. Pass [] for all types.
maxResultsintegerMaximum companies to return, e.g. 500. Default 100. You pay per company delivered.
onlyNewSinceLastRunbooleantrue = skip (and don't charge for) companies an earlier run with the same filters already delivered. For scheduled runs. Default false. Remembered in a named key-value store in your account. E.g. true for a daily scheduled run.

Sources, licence and limits

How fresh is it? Runs read the live Companies House API. A company appears once Companies House has registered it; run after the day is over (the default, yesterday) for a complete day.

Why no directors or owners? Officer and PSC (beneficial owner) names are personal data. This Actor returns company-level data only and never requests those endpoints. Use the source_url to look a company up on the register yourself.

Is the registered office a personal address? It is the company's official public address on the register. Small companies sometimes use a home or an accountant's address; it is still published by Companies House as the company's address. If you contact companies, UK direct-marketing rules (PECR, UK GDPR) apply to you.

How does the SIC filter work? Your prefix is expanded to every matching code on the Companies House condensed SIC 2007 list (e.g. 62 = 62011, 62012, 62020, 62030, 62090), and a company matches if any of its declared codes is in that set. Companies choose their own codes, so they are a guide, not an audit.

How does location work? It is passed to Companies House's own location filter (registered office address). For exact postcode-area targeting, filter on postcode_area afterwards.

Which date is "yesterday"? Yesterday in UTC.

Limits? Up to 10,000 companies per run. For long ranges, split by month.

Legal basis? Companies House: "We impose no rules or requirements on how the information on the public register is used." Source: Companies House. See LEGAL.md in the repository.
