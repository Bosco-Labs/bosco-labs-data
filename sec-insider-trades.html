SEC Insider Trading API (Form 4): live + history since 2006

Insider trading data from SEC Form 4: every insider purchase and sale by directors, officers and 10% owners, from official EDGAR filings, 2006 to today.

Filter by ticker, CIK, transaction code, role, value and date; adds cluster-buy and cluster-sell signals. Use for insider screens and alerts.

Coverage

Today's filings from the EDGAR live feed, minutes after the SEC accepts them; recent quarters from the EDGAR indexes and Form 4 XML; history from 2006 from the SEC's quarterly Insider Transactions Data Sets. Non-derivative table only: options and other derivatives are not included.

Price

Pricing (pay per event): $0.0018 per transaction row ($1.80 per 1,000) and $0.02 per cluster signal. No start fee. You only pay for rows delivered, a transaction is never charged twice in a scheduled feed, and the Actor stops at your max charge limit.

Input fields

FieldTypeMeaning
tickersarrayIssuer stock tickers, e.g. ["AAPL", "TSLA"]. Mapped to the company's CIK with the SEC's own ticker list; history is also matched on the ticker as written in the filing. Empty (and ciks empty) = the whole market.
ciksarrayIssuer SEC Central Index Keys as digits, leading zeros optional, e.g. ["320193"] for Apple. Use for delisted or renamed companies the SEC's ticker list no longer has. Empty = no CIK filter.
transactionCodesarrayForm 4 transaction codes to return, e.g. ["P"] for open-market purchases only. Default ["P", "S"] (open-market purchases and sales). Pass [] for all codes, including awards (A), tax withholding (F) and option exercises (M).
insiderRolesarrayOnly insiders with one of these roles: director, officer, ten_percent_owner, other, e.g. ["director", "officer"]. Empty = all roles.
minValueUsdintegerMinimum transaction value in USD (shares x price), e.g. 100000. Default 0 = no minimum. Transactions without a price count as 0.
dateFromstringEarliest filing date, YYYY-MM-DD, e.g. "2024-01-01". Data starts 2006-01-01. Empty = lookbackDays days before today.
dateTostringLatest filing date, YYYY-MM-DD, e.g. "2024-12-31". Empty = today, including today's filings from the live EDGAR feed.
lookbackDaysintegerUsed only when dateFrom is empty: read filings from this many days back until today, e.g. 90. Default 7. Handy for schedules.
clusterBuysOnlybooleantrue = only open-market purchases that are part of a cluster: at least 2 different directors or officers of the same company buying, filed within clusterWindowDays, together worth at least $100,000. Default false. Also reads the window before the date range.
clusterSellsOnlybooleantrue = only open-market sales that are part of a cluster (same rule as cluster buys, for sales). Pre-planned 10b5-1 plan sales are left out (filings flag them since April 2023). Default false. Can be combined with clusterBuysOnly.
clusterWindowDaysintegerHow many days of filings count as one cluster of insider buying or selling, e.g. 14. Default 30.
includeClusterSignalsbooleantrue (default) = also output one row per cluster signal (record_type = "cluster"): the day a company's insider buying or selling first met the cluster rule, with the insiders and total value. Charged as a separate, higher-priced event. false = transaction rows only.
maxResultsintegerMaximum transaction rows, newest first, e.g. 500. Default 100, up to 200,000 per run (split bigger exports by date range). The run stops reading once it has this many, and returns at most this many cluster signals.
onlyNewSinceLastRunbooleantrue = skip (and don't charge for) transactions and signals an earlier run with the same filters already delivered. For scheduled runs. Default false. Remembered in a named key-value store in your account.
