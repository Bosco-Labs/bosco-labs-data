Annual report figures of EU listed companies as JSON

Bosco Labs · 17 November 2026

Every company listed on a regulated market in the EU files its annual report in ESEF: an XHTML document with the financial statements tagged in XBRL. The tags are what make it machine-readable, but reading them yourself means unpacking a report package, resolving contexts and picking the right IFRS concept out of a few thousand facts. Our EU Annual Reports API on Apify does that and returns the main figures as one row per company per year.

One company, latest year

The input for Heineken's latest annual report:

{"companyName": "heineken", "maxFilings": 1}

What came back on 17 November 2026, trimmed:

Reading the row

  • The name search found Heineken Holding N.V., the listed holding company that owns a majority of Heineken N.V. Both file their own report. When you need one specific company, search by its LEI ("leis": ["..."]) instead of a name.
  • net_income and net_income_attributable_to_parent differ a lot here: 2.14 billion for the whole group against 952 million for the holding's own shareholders, because about half of Heineken N.V. belongs to other shareholders. For earnings per share and valuation, use the attributable figure.
  • sources names the IFRS concept and period behind every reported figure, and marks the ones we calculate (ebitda, the margins, total_liabilities) as derived with the formula. viewer_url opens the tagged report itself, so you can click through to any number.
  • prior_year holds the same figures for the year before, as filed in this report, so revenue_growth needs no second call.

More than one company

countries takes ISO codes (["NL", "BE", "FR"]) and periodFrom/periodTo limit the fiscal years; leave the name out to list every report in that range, newest first. The reports come from filings.xbrl.org, which collects ESEF filings from the national storage mechanisms. Set includeRawFacts to also get every tagged fact of a report as its own row, and onlyNewSinceLastRun on a schedule to pay only for reports you haven't seen.

Run it

On the Store page, click Try for free, paste the input and press Start. From Python, with Apify's official client (pip install apify-client):

from apify_client import ApifyClient

client = ApifyClient("<APIFY_TOKEN>")
run = client.actor("bosco_labs/esef-annual-reports").call(run_input={
    "companyName": "heineken",
    "maxFilings": 1,
})
for row in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(row["company_name"], row["period_end"], row["revenue"], row["net_income"])
