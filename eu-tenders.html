EU Public Tenders & Contract Awards API (TED procurement)

Coming soon to the Store

Get European public tenders and contract awards as clean, predictable JSON from TED, filtered by keyword, buyer country, CPV code, notice type, date and value: open calls for tenders with their deadline and estimated value, award notices with the winning companies and the awarded amount, and prior information notices about planned purchases. One row per notice, the same field names for every country and notice form. For bid teams, tender-alert services, market researchers and AI agents.

Coverage

Every country that publishes on TED: the 27 EU member states, Norway, Iceland, Liechtenstein, Switzerland, candidate countries and EU-funded procurement abroad; about 22,000 notices a week. History from November 2016 (complete from 2017). New notices are available the day they are published.

Input fields

FieldTypeMeaning
keywordsstringFull-text search over the whole notice, in any language; a notice matches when it contains all words, e.g. "cloud hosting". Empty = no keyword filter.
countriesarrayBuyer countries as ISO 3166 alpha-2 (DE, FR, NL, PL, ...) or alpha-3 (DEU) codes, e.g. ["DE", "NL"]. Alpha-3 works for any country, e.g. UKR. Empty = all countries.
cpvCodesarrayCommon Procurement Vocabulary (CPV) code prefixes as digit strings; a prefix matches every code below it, e.g. ["72"] = IT services, "45" = construction work, "3312" = medical equipment, "72212000" = one specific code. Empty = all sectors.
noticeTypesarrayKinds of notices: contract_notice (open call for tenders), contract_award (who won, for how much), prior_information, direct_award_preannouncement, contract_modification, market_consultation. Default ["contract_notice"]. Pass [] for all kinds.
publishedFromstringEarliest publication date, YYYY-MM-DD, e.g. "2026-10-01". The TED API covers notices from November 2016. Empty = 7 days before publishedTo.
publishedTostringLatest publication date, YYYY-MM-DD. Empty = today.
minValueEurintegerMinimum total notice value in EUR, e.g. 1000000 (estimated value for calls, awarded value for awards). When set, notices stated in other currencies (e.g. PLN, SEK) and notices without a value are left out, as TED does not convert currencies. Empty = no minimum.
maxResultsintegerMaximum notices, newest first, e.g. 100. Default 50. You pay per notice delivered.
onlyNewSinceLastRunbooleantrue = skip (and don't charge for) notices an earlier run with the same filters already delivered. For scheduled runs. Default false. Remembered in a named key-value store in your account.

Sources, licence and limits

Which countries? Every country that publishes on TED: the 27 EU member states, the EEA (Norway, Iceland, Liechtenstein), Switzerland, candidate countries and EU-funded procurement abroad. Use ISO codes; for countries outside Europe, use the alpha-3 code (e.g. UKR).

How fresh? TED publishes a new edition every working day. Runs read the live API, so new notices are available the day they are published.

Why is a field empty? It isn't in the notice. Award notices have no deadline, many contract notices state no estimated value, and older (pre-eForms) notices have fewer fields.

How does minValueEur work? It uses TED's total value of the notice: the estimated value for calls and the awarded value for awards. TED does not convert currencies, so with this filter set, notices stated in other currencies (PLN, SEK, CZK, ...) and notices without a value are left out. Leave it empty for non-euro countries.

Which language? Titles are in English (TED translates them into all EU languages). Descriptions are in the language the buyer wrote them in, unless an English version exists; description_language tells you which.

Can I get older notices? Yes: set publishedFrom and publishedTo. The TED API covers notices from November 2016 onwards (complete from 2017; checked 2026-11-05), and there is no 15,000-notice cap per run.

Contact details? Not included. Rows contain no contact persons, e-mail addresses or phone numbers, even where TED publishes them; they are also removed from descriptions.

Legal basis? TED notices may be freely reused for commercial and non-commercial purposes (Commission Decision 2011/833/EU, see the TED legal notice). Winner names are published by law; some winners are sole traders (natural persons), so if you process the data further, you are responsible for your own legal basis under GDPR.
