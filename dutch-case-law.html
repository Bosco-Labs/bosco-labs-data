Input fields

FieldTypeMeaning
eclistringOne or more Dutch ECLIs, separated by commas or spaces, e.g. "ECLI:NL:HR:2024:123" or "ECLI:NL:HR:2024:123, ECLI:NL:RVS:2024:1000" (max 100). Lower case and uitspraken.rechtspraak.nl links also work. One row per ECLI; an unknown ECLI fails at no charge. Empty = search with the fields below (both can be combined: ECLI rows come first).
querystringWords to find in the decision's title and summary (inhoudsindicatie), case-insensitive. Commas separate alternatives, words within one alternative must all appear: "huur, pacht" = huur OR pacht; "ontslag op staande voet" = all four words. Summaries are in Dutch, so use Dutch words. The official API has no full-text search: this filters the newest-updated decisions that match the other filters (up to 10,000 scanned). Empty = no keyword filter.
courtsarrayCourt codes as used in the ECLI, e.g. ["HR"] for the Hoge Raad (Supreme Court); others: PHR (Procureur-Generaal/AG opinions), RVS (Raad van State), CRVB, CBB, GHAMS, GHARL, GHDHA, GHSHE (courts of appeal), RBAMS, RBDHA, RBROT, RBMNE ... (district courts). Full Dutch names also work. Empty = all courts.
legalAreasarrayRechtsgebied names, e.g. ["Strafrecht"], ["Belastingrecht", "Arbeidsrecht"]; English also works: criminal, civil, administrative, tax, employment, immigration, insolvency, family, competition, environmental. A main area includes its sub-areas. Empty = all areas.
dateFromstringEarliest decision date (uitspraakdatum), YYYY-MM-DD, e.g. "2024-01-01". Empty = no lower limit (to today if dateTo is empty).
dateTostringLatest decision date, inclusive, YYYY-MM-DD, e.g. "2024-12-31". Empty = today when dateFrom is set, else no limit.

Sources, licence and limits

Where does the data come from? Only from the Open Data service of the Dutch judiciary (Rechtspraak, data.rechtspraak.nl): the ECLI index and the decision XML. Nothing is added, rewritten or summarised; the summary is the court's own inhoudsindicatie.

Which courts? Everything Rechtspraak publishes: Hoge Raad and its Procureur-Generaal (PHR), Raad van State, Centrale Raad van Beroep, College van Beroep voor het bedrijfsleven, the four courts of appeal, the eleven district courts, the Caribbean courts and several disciplinary tribunals, from the 1990s on. Courts publish only a selection of their decisions, so absence from Rechtspraak does not mean a case does not exist.

Personal data? Courts pseudonymise decisions before publishing them: parties and other private persons appear as [eiser], [verdachte], [adres] and so on. This Actor returns the published text as is, adds nothing, links nothing to other sources and offers no search by person. Do not use it to try to re-identify anyone.

How current is it? Live: every run reads data.rechtspraak.nl. New decisions appear the day Rechtspraak publishes them, usually days to weeks after the decision date.

Is this legal advice? No. It returns published decisions and their metadata; it does not interpret them. English translations of some landmark decisions are unofficial (the courts say so in the summary); the Dutch text is authentic.

Limits: 100 ECLIs or 200 search results per run; no full-text search (see above); no filter by procedure type (the API has none; procedures is in every row); text cut at maxTextChars. Rechtspraak asks users to stay under 10 requests per second, so this Actor reads one decision at a time.

Content: decisions of the Dutch courts via Rechtspraak Open Data, https://www.rechtspraak.nl/uitspraken/open-data (court decisions carry no copyright, art. 11 Auteurswet). Text is converted from XML to plain text and long texts are cut where maxTextChars says; nothing else is changed.
