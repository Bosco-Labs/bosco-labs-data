# Bosco Labs data APIs

Documentation site for the Bosco Labs data APIs: Apify Actors that return clean, typed JSON from
official sources (SEC Form 4 insider trades and EDGAR filings, US House STOCK Act trades,
European ESEF annual reports, UK/Danish/Norwegian company accounts, EU public tenders from TED,
Pentagon contract awards) plus two Apify dataset tools.

- Site: https://pb7-debug.github.io/bosco-labs-data/
- For AI agents and LLMs: [`llms.txt`](llms.txt) and [`llms-full.txt`](llms-full.txt)
- Run the Actors: [Bosco Labs on Apify Store](https://apify.com/bosco_labs)

The site is plain static HTML served by GitHub Pages. Every file except `README.md`, `.nojekyll`
and the logos is generated by `build.py` (Python standard library only) from the Actors' schema
files and READMEs; `python build.py --check` validates the generated pages (title and meta
description length, Store links, JSON-LD).
