SEC EDGAR Filings API: 8-K, 10-K, 10-Q feed since 1994

SEC EDGAR filings (8-K, 10-K, 10-Q, S-1, 13D, 13G, Form 4 and every other form) for any company or the whole market, live or back to 1994, from the SEC's own feeds.

Filter by ticker, CIK, form, 8-K item and date; flags earnings releases (Item 2.02). Returns links to each filing, not its text.

Coverage

All EDGAR forms. Companies: the SEC submissions API, complete history back to 1994. Whole market: the live feed, then the EDGAR daily and quarterly indexes back to 1993. 8-K item codes exist since August 2004. Rows hold links to the filing and its main document, not the document text.

Price

Pricing (pay per event): $0.001 per filing ($1 per 1,000). No start fee. You only pay for filings delivered, a scheduled feed never charges the same filing twice, and the Actor stops at your max charge limit.

Input fields

FieldTypeMeaning
formTypesarrayEDGAR form types, exact match, e.g. ["8-K", "10-K", "10-Q"]; also S-1, 13D, 13G, 4, DEF 14A, 20-F, 6-K and any other form. Add "10-K/A" etc. for amendments. 13D and 13G also match the SC 13D and SCHEDULE 13D names. Empty = every form.
tickersarrayCompany tickers, e.g. ["AAPL", "MSFT"]. Mapped to the CIK with the SEC's own company_tickers.json. Empty (and ciks empty) = the whole market.
ciksarraySEC Central Index Keys as digits, leading zeros optional, e.g. ["320193"] for Apple. Use for delisted companies, funds and filers without a ticker. Empty = no CIK filter.
earningsReleasesOnlybooleantrue = only 8-Ks with Item 2.02 (Results of Operations and Financial Condition): the dates and exact times companies released earnings. Overrides formTypes and itemCodes. Default false.
itemCodesarrayOnly 8-Ks reporting at least one of these items, as strings, e.g. ["5.02"] (director/officer change), "1.01" (material agreement), "2.01" (acquisition), "1.05" (cybersecurity incident). Without formTypes, reads 8-K and 8-K/A. Empty = no item filter.
dateFromstringEarliest filing date, YYYY-MM-DD, e.g. "2020-01-01". EDGAR's index goes back to 1993. Empty = lookbackDays days before today, so set this (or lookbackDays) to get older filings.
dateTostringLatest filing date, YYYY-MM-DD. Empty = today, including filings accepted minutes ago (live EDGAR feed).
lookbackDaysintegerUsed only when dateFrom is empty: read filings from this many days back until today, e.g. 365. Default 7, so a company's older filings need a larger value or dateFrom.
maxResultsintegerMaximum filings, newest first, e.g. 20. Default 100. The run stops once it has this many.
onlyNewSinceLastRunbooleantrue = skip (and don't charge for) filings an earlier run with the same filters already delivered. For scheduled runs. Default false. Remembered in a named key-value store in your account.

Use with AI agents

Add this URL to your MCP client (Claude, Cursor, VS Code, ...) to load the Actor as a tool through the Apify hosted MCP server. It signs you in with OAuth or accepts Authorization: Bearer <APIFY_TOKEN>.

https://mcp.apify.com?tools=bosco_labs/sec-filings-feed

Example prompt: “"When did Nvidia release its last four quarterly results, and was it before or after the market closed?"” The agent passes:

{"tickers": ["NVDA"], "earningsReleasesOnly": true, "lookbackDays": 400, "maxResults": 4}

stable, typed JSON, one row per filing. Every row has schema_version and a source_url pointing to the SEC data it came from, plus filing_index_url and primary_document_url for the filing itself, so the agent can cite its source. Without dateFrom, a run reads only the last lookbackDays days (default 7), so set one of them for history.

Or call the Apify API: POST https://api.apify.com/v2/acts/bosco_labs~sec-filings-feed/run-sync-get-dataset-items with the input as JSON body. Cost: $0.001 per filing.
