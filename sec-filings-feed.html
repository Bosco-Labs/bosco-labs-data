SEC EDGAR Filings API: 8-K, 10-K, 10-Q feed since 1994

On Apify Store

Get SEC EDGAR filings as clean JSON: 8-K current reports, 10-K annual reports, 10-Q, S-1, 13D, 13G, Form 4, DEF 14A, 20-F and every other form, for one company, a watchlist or the whole market, from filings accepted minutes ago back to 1994. Coverage

All EDGAR forms. Companies: the SEC submissions API, complete history back to 1994. Whole market: the live feed, then the EDGAR daily and quarterly indexes back to 1993. 8-K item codes exist since August 2004. Rows hold links to the filing and its main document, not the document text.

Input fields

FieldTypeMeaning
formTypesarrayEDGAR form types, exact match, e.g. ["8-K", "10-K", "10-Q"]; also S-1, 13D, 13G, 4, DEF 14A, 20-F, 6-K and any other form. Add "10-K/A" etc. for amendments. 13D and 13G also match the SC 13D and SCHEDULE 13D names. Empty = every form.
tickersarrayCompany tickers, e.g. ["AAPL", "MSFT"]. Mapped to the CIK with the SEC's own company_tickers.json. Empty (and ciks empty) = the whole market.
ciksarraySEC Central Index Keys as digits, leading zeros optional, e.g. ["320193"] for Apple. Use for delisted companies, funds and filers without a ticker. Empty = no CIK filter.
earningsReleasesOnlybooleantrue = only 8-Ks with Item 2.02 (Results of Operations and Financial Condition): the dates and exact times companies released earnings. Overrides formTypes and itemCodes. Default false.
itemCodesarrayOnly 8-Ks reporting at least one of these items, as strings, e.g. ["5.02"] (director/officer change), "1.01" (material agreement), "2.01" (acquisition), "1.05" (cybersecurity incident). Without formTypes, reads 8-K and 8-K/A. Empty = no item filter.
dateFromstringEarliest filing date, YYYY-MM-DD, e.g. "2020-01-01". EDGAR's index goes back to 1993. Empty = lookbackDays days before today (or, for tickers/CIKs without lookbackDays, the company's newest filings).
dateTostringLatest filing date, YYYY-MM-DD. Empty = today, including filings accepted minutes ago (live EDGAR feed).
lookbackDaysintegerUsed only when dateFrom is empty: read filings from this many days back until today, e.g. 365. Empty = 7 days for the whole market; for tickers/ciks, empty = each company's newest filings (its last 1,000), so "latest 10-K of AAPL" needs no dates.
maxResultsintegerMaximum filings, newest first, e.g. 10 for a company's latest 10 filings. Default 100. The run stops once it has this many; you pay per filing returned.
onlyNewSinceLastRunbooleantrue = skip (and don't charge for) filings an earlier run with the same filters already delivered. For scheduled runs. Default false. Remembered in a named key-value store in your account.

Sources, licence and limits

Which forms? All of them: whatever EDGAR accepts, from 10-K to N-PORT. Use the exact form type as EDGAR names it.

Since when do 8-Ks have items? The numbered items (2.02 etc.) exist since August 2004; older 8-Ks have an empty items list. Filings from the 1990s have a date but no acceptance time, so market_timing is null there.

Why is the ticker empty sometimes? Tickers come from the SEC's current ticker list. Delisted companies, funds and private filers have none; their CIK always works.

Company names? For company searches, the current name in the SEC's records (Apple Inc. for 1994 filings too); for whole-market searches, the name on the filing.

Do I get the documents' text? No, links only (primary_document_url, filing_index_url). That keeps rows small and cheap; fetch the documents you need.

Legal basis? SEC filings are US government public records. See LEGAL.md.
