Get a key

Enter your e-mail address. We send a one-time link; the page it opens shows your key once and adds $5.00 of free credit (one trial per e-mail address).

Lost your key? Send the same e-mail address again: the link gives you a new key for the same account, the old key stops working, apps linked to it (ChatGPT or Claude connectors) are unlinked and your balance stays. Balance and top-ups: Account.

Quick start

curl https://api.boscolabs.dev/v1/eu-rates-inflation \
  -H "Authorization: Bearer $BOSCO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"series": ["ecb_deposit_rate", "hicp:EA"], "last": 3}'

Python (pip install httpx):

import os, httpx

r = httpx.post(
    "https://api.boscolabs.dev/v1/eu-rates-inflation",
    headers={"Authorization": f"Bearer {os.environ['BOSCO_API_KEY']}"},
    json={"series": ["ecb_deposit_rate", "hicp:EA"], "last": 3},
    timeout=60,
)
body = r.json()
if r.status_code != 200:
    raise SystemExit(body["error"]["message"])  # failed calls are never charged
for row in body["rows"]:
    print(row["series"], row["latest_value"], row["source_url"])

JavaScript (Node 18+ or the browser):

const r = await fetch("https://api.boscolabs.dev/v1/eu-rates-inflation", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.BOSCO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ series: ["ecb_deposit_rate", "hicp:EA"], last: 3 }),
});
const body = await r.json();
if (!r.ok) throw new Error(body.error.message); // failed calls are never charged
for (const row of body.rows) console.log(row.series, row.latest_value, row.source_url);

Every call is POST /v1/<tool> with the Actor's input object as JSON. A 200 answer is {"tool", "rows": [...], "count", "warnings", "message", "charged_usd", "balance_usd", "duration_seconds"}; the headers X-Credits-Charged and X-Credits-Balance repeat the charge. An empty result is 200 with rows: [] and costs nothing. Check your balance with GET /v1/me; list tools, prices and input schemas with GET /v1/tools (free).

Not sure which tool? POST /v1/plan with {"question": "..."} (free, no key) returns the exact calls, their input and maximum price, and what is not covered; GET /v1/tools/<tool> describes one tool. POST /v1/run with that plan_id and a required max_usd runs all steps in parallel on your key, each charged like a direct call; nothing runs if the worst case is above max_usd.

x402: pay per call without an account

No key, no sign-up: an agent with a wallet can pay each call in USDC on Base through x402. Call POST https://api.boscolabs.dev/v1/<tool> without an API key and you get 402 Payment Required with a PAYMENT-REQUIRED header (x402 v2) that states the price; an x402 client signs the payment and retries on its own.

  • USDC on Base mainnet (eip155:8453), settled through the Coinbase CDP facilitator.
  • Two schemes are offered. upto (offered first): you authorize the quoted maximum and we settle only what was delivered, rows times the tool's price, at least $0.005 per paid call. exact: the quote is settled.
  • With upto the wallet needs only USDC on Base: the approval is a gasless permit, so no ETH for gas.
  • Empty answers are free: 404 with error.code: "no_results", nothing settled.
  • Same prices as credits, listed above and in GET /v1/tools. A paid 200 carries paid_via: "x402" and charged_usd; the payment-response header holds the settlement (base64 JSON with the transaction hash).

Python (pip install "x402[evm]>=2.27,<3" httpx eth-account), with the key of a dedicated wallet that holds a few dollars of USDC:

import asyncio, base64, json, os
from eth_account import Account
from x402 import x402Client
from x402.http.clients.httpx import x402HttpxClient
from x402.mechanisms.evm.signers import EthAccountSignerWithRPC
from x402.mechanisms.evm.upto.client import UptoEvmScheme

async def main():
    account = Account.from_key(os.environ["X402_PRIVATE_KEY"])
    client = x402Client()
    client.register("eip155:8453", UptoEvmScheme(EthAccountSignerWithRPC(account, "https://mainnet.base.org")))
    async with x402HttpxClient(client, timeout=90) as http:
        r = await http.post("https://api.boscolabs.dev/v1/eu-rates-inflation", json={"series": ["ecb_deposit_rate"], "last": 1})
    body = r.json()
    print(r.status_code, body.get("paid_via"), body.get("charged_usd"))
    if settled := r.headers.get("payment-response"):
        print("tx", json.loads(base64.b64decode(settled))["transaction"])

asyncio.run(main())

TypeScript: use wrapFetchWithPaymentFromConfig from @x402/fetch with UptoEvmScheme from @x402/evm/upto/client; see the official x402 fetch docs.

Rate limits

  • About 60 calls per minute per key (10 per minute on free-trial keys); counted per server instance, so treat it as approximate.
  • Daily spending cap per key: $5 by default, raised on request.
  • Each call has a 55-second budget. Some tools pace their source (for example, UK and Dutch law lookups wait 5 seconds between pages), so a call can take up to about 35 seconds. Counterparty check is the slowest: it combines several sources and can take 20 seconds or more.

Errors

Every error has one shape: {"error": {"code", "message", "example"?}}. Failed calls are never charged. Empty results differ per channel: with a key, 200 with rows: []; with x402, 404 no_results; nothing is charged either way.

HTTPCodeMeaning
400invalid_inputBad input: the Actor's own validation message, often with an example.
401bad_keyMissing, unknown or disabled key.
404no_resultsx402 calls only: nothing billable in the answer, so the payment is not settled. With a key an empty result is not an error: 200 with rows: [], nothing charged.
402insufficient_creditsBalance below price x maximum rows for this input; shows your balance and how to buy credits.

MCP

Add https://api.boscolabs.dev/mcp (streamable HTTP) to your MCP client with the header Authorization: Bearer <key>. It lists three tools: counterparty_check, plan_official_records_query (free) and run_official_records_plan, which runs a plan or any tool above by name. To list each tool above as its own MCP tool, at the same price, use https://api.boscolabs.dev/mcp?tools=all; every tool can be called by name on either URL.

In Claude (claude.ai, Desktop and mobile): Settings → Connectors → Add custom connector, URL https://api.boscolabs.dev/mcp/claude. Claude opens our sign-in page once; paste your API key there to link it. Calls are billed to that key at the prices above, and replacing your key unlinks Claude. The planner tools are free on every call.

Versioning and changes

The API is in beta. What we aim for while it is:

  • Keep /v1 backward compatible: we add tools and optional fields, and avoid renaming or removing fields.
  • A breaking change gets a new prefix (/v2), announced on this page in advance.
  • Every row has a schema_version; parse rows by field name and ignore fields you don't know.
  • Price changes are announced at least 14 days ahead; a call is charged the price shown in GET /v1/tools when it runs.
