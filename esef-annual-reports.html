EU Annual Reports API (ESEF): XBRL financial statements

Key financials (revenue, EBIT, net income, EPS, assets, equity, cash flows, margins, growth) from ESEF annual reports of European listed companies in 28 countries, via filings.xbrl.org.

Each value links to its XBRL fact. Filter by LEI, company name, country and fiscal year end.

Coverage

ESEF annual reports collected by filings.xbrl.org: 27,626 reports from 28 countries (counted 2026-11-05; largest: UA, GB, DK, SE, NO, FR, FI). Germany is not in the index. Reports appear a few days to a few weeks after publication, once filings.xbrl.org has processed them. All values are in full currency units.

Price

Pricing (pay per event): $0.01 per run plus $0.05 per annual report ($50 per 1,000 reports). Each report includes the comparative prior year at no extra cost. Raw XBRL fact rows, if you switch them on, cost $0.0005 each. You only pay for reports delivered, the same fiscal year is never charged twice, and the Actor stops at your max charge limit.

Input fields

FieldTypeMeaning
leisarrayLegal Entity Identifiers (20 characters), e.g. ["724500Y6DUVHQD6OXN27"] for ASML. Combined with countries (default NL), so also pass countries: [] or the company's country for non-Dutch companies. Empty = no LEI filter.
companyNamestringCase-insensitive part of the registered company name, e.g. "heineken". Combined with countries (default NL), so also pass countries: [] or the company's country for non-Dutch companies. Empty = no name filter.
countriesarrayFiling countries as ISO 3166 alpha-2 codes, e.g. ["NL", "BE", "FR"]; also SE, DK, FI, NO, IT, ES, GB and others. Default ["NL"]. Pass [] for all 28 countries in the index (Germany is not in it).
periodFromstringFiscal year ending on or after this date, YYYY-MM-DD, e.g. "2024-01-01". Empty = no lower limit.
periodTostringFiscal year ending on or before this date, YYYY-MM-DD, e.g. "2024-12-31". Empty = no upper limit.
maxFilingsintegerMaximum annual reports, newest fiscal period first, e.g. 1 for a company's latest report. Default 10. One report per company per fiscal year, with the prior year nested in each row.
includeRawFactsbooleantrue = also output every tagged XBRL fact of each report as its own row (record_type = "fact"), charged per fact row. Default false (one summary row per report).
onlyNewSinceLastRunbooleantrue = skip (and don't charge for) reports an earlier run with the same filters already delivered. For scheduled runs. Default false. Remembered in a named key-value store in your account.
