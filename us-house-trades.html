Congress Stock Trades API: US House STOCK Act since 2014

Congress stock trades: stock, option, fund and bond trades that US House members disclose in STOCK Act Periodic Transaction Reports, from the Clerk's official filings since 2014 (no Senate).

Each row: ticker, amount range, owner, disclosure delay. Filter by member, ticker, type, amount, date.

What you get

FieldTypeMeaning

asset_descriptionstringAsset text as filed (older PDFs garble upper/lower case).
asset_typestring | nullFrom asset_type_code: ST = stock, OP = option, EF/MF = fund, GS/CS = bond, other codes = other. Filings before ~2018 have no code: option if the description says so, else null.
asset_type_codestring | nullThe Clerk's asset type code in square brackets, e.g. ST, OP, EF, GS (see fd.house.gov/reference/asset-type-codes.aspx).
option_typestring | nullcall or put, from the transaction description, for options only.
transaction_typestringP = purchase, S / S (partial) = sale, E = exchange.
is_partialbooleanTrue for a partial sale (S (partial)).
amount_minnumber | nullLower bound of the reported value range in USD, e.g. 15001; the value itself when the filer reported an exact amount (e.g. 318.74).
amount_maxnumber | nullUpper bound of the reported value range in USD; null for 'Over $50,000,000' and 'Spouse/DC Over $1,000,000'.
amount_textstringThe value range (or exact value) as filed, e.g. $15,001 - $50,000.
is_amendmentbooleanTrue when the transaction's filing status is Amended: the filing date is then not when the trade first became public.
doc_idstringThe Clerk's document (filing) ID.
pdf_urlstringThe PTR PDF on disclosures-clerk.house.gov.
source_urlstringWhere the row was extracted from (the PTR PDF).
retrieved_atstringUTC time the PDF was fetched and parsed.

Coverage

Periodic Transaction Reports of House members filed online, from January 2014 to the latest update of the Clerk's index. Scanned paper PTRs are skipped (their PDF links are listed in the run's SUMMARY record). The Senate and annual financial disclosure reports are not included.

Price

Pricing: $1.80 per 1,000 trades ($0.0018 per trade), no start fee. You only pay for trades delivered, and the Actor stops at your max charge limit.

Input fields

FieldTypeMeaning
membersarrayCase-insensitive part of the member's name as listed by the Clerk, e.g. ["Pelosi"] or ["Josh Gottheimer"]. Empty = all House members.
tickersarrayOnly trades whose filing names one of these tickers, e.g. ["NVDA", "MSFT", "BRK.B"]. Trades without a ticker in the filing are left out when this is set. Empty = all.
transactionTypesarrayAny of purchase, sale (full or partial), exchange, e.g. ["purchase"]. Default all three.
filedFromstringEarliest filing date (when the trade became public), YYYY-MM-DD, e.g. "2025-01-01". Empty = 365 days ago when members is set, else 30 days ago; ignored when years is set without dates.
filedTostringLatest filing date, YYYY-MM-DD, e.g. "2025-12-31". Empty = today.
yearsarrayWhole filing years to load, as strings, e.g. ["2024", "2025"] (one Clerk index per year; online PTRs start in 2014). Without dates, returns those whole years. Use this or filedFrom for history.
minAmountUsdintegerOnly trades whose reported range starts at or above this USD amount, e.g. 15001 leaves out the smallest $1,001 - $15,000 range, 1000001 keeps trades over $1 million. Empty = no minimum.
maxResultsintegerMaximum trades, newest filings first, e.g. 500. Default 100. You pay per trade returned.
onlyNewSinceLastRunbooleantrue = skip (and don't charge for) trades an earlier run with the same filters already delivered. For scheduled runs. Default false. Remembered in a named key-value store in your account.
