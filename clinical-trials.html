Input fields

FieldTypeMeaning
nctIdsarrayClinicalTrials.gov identifiers to look up, NCT + 8 digits, e.g. ["NCT05813925"]. Up to 100, in one API call; one row per trial found, in the order given. When set, all search filters below are ignored. Empty = search mode.
conditionstringCondition or disease to search for, e.g. "obesity" or "non-small cell lung cancer". Matches ClinicalTrials.gov's condition field including its synonyms; supports OR/AND, e.g. "obesity OR overweight". Empty = any condition.
interventionstringDrug, biologic, device or procedure name, e.g. "semaglutide" or "semaglutide OR tirzepatide". Use molecule or brand names; a drug class like "GLP-1" only matches trials that write it. Empty = any intervention.
sponsorstringLead sponsor organisation, e.g. "Novo Nordisk" (matches "Novo Nordisk A/S"). Searches the lead sponsor only, not collaborators. Empty = any sponsor.
phasearrayTrial phases to include, any of EARLY_PHASE1, PHASE1, PHASE2, PHASE3, PHASE4, NA, e.g. ["PHASE3"]. A phase 2/3 trial matches both PHASE2 and PHASE3. Empty = all phases (observational studies have none).
statusarrayOverall recruitment status of the trial, e.g. ["RECRUITING", "NOT_YET_RECRUITING"]. UNKNOWN = status not verified for over 2 years. Empty = any status.
locationCountriesarrayTrials with at least one site in any of these countries, e.g. ["Germany", "DK"] or ["Europe"]. Accepts country names as ClinicalTrials.gov writes them ("United States", "South Korea", "Czechia"), common ISO alpha-2 codes, and the regions "Europe" (45 European countries incl. UK, Switzerland, Norway, Ukraine) and "EU" (27 member states). Empty = anywhere.
startDateFromstringEarliest trial start date (actual or planned), YYYY-MM-DD, YYYY-MM or YYYY, e.g. "2025-01-01". Inclusive. Empty = no lower bound.
startDateTostringLatest trial start date, YYYY-MM-DD, e.g. "2025-12-31". Inclusive. Empty = no upper bound (includes planned future starts).
primaryCompletionFromstringEarliest primary completion date (actual or estimated: when the primary endpoint data are complete, the usual read-out catalyst), YYYY-MM-DD, e.g. "2026-01-01". Empty = no lower bound.
primaryCompletionTostringLatest primary completion date, YYYY-MM-DD, e.g. "2026-12-31". Empty = no upper bound.
hasResultsbooleantrue = only trials with results posted on ClinicalTrials.gov; false = only trials without. Leave empty (omit) for both. E.g. true.

detailstring"summary" (default): the compact dossier. "full" also fills eligibility (criteria up to 4,000 characters, sex, ages), arms (up to 20), secondary outcomes (up to 15) and sites (facility, city, country, status; up to 100). Same price.

Sources, licence and limits

How fresh is it? Live: every run queries ClinicalTrials.gov, which updates its data daily (data_processed_at is its latest processing time). Sponsors update their own records, so a status can lag reality; last_update_posted shows when the record last changed.

Does "recruiting in Europe" mean the European sites are recruiting? It means the trial's overall status is recruiting and at least one site is in Europe. Per-site status is in sites[].status with detail: "full".

Why does a drug class like "GLP-1" find few trials? The intervention search matches what registrants wrote. Name the molecules (semaglutide OR tirzepatide ...) for full coverage.

Are results (outcome data) included? has_results and results_first_posted say whether and when results were posted; the result tables themselves are not included (open source_url).

What is left out? Contact persons, investigators and officials (names, emails, phones); the responsible-party investigator; detailed descriptions, references, IPD-sharing and oversight details. When the record lists a private individual as lead sponsor (class INDIV), sponsor is null; some sponsor-investigators are registered under class OTHER and do appear by name, as on ClinicalTrials.gov.

Coverage? Everything on ClinicalTrials.gov (over 500,000 studies worldwide, US and non-US). Trials registered only elsewhere (EU CTIS, ISRCTN, jRCT, ...) are not included.
