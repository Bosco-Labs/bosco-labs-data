Which Entity List rules did BIS publish in the Federal Register in 2026?

Answered byUS Federal Rules API: CFR text as of a date + Federal Register
Price$0.001 per unit: a CFR section with text = 5 units ($0.005), a Federal Register document = 2 ($0.002); rows without text are free (HTTP API)
StatusOn the HTTP API

BIS adds and removes Entity List parties through final rules in the Federal Register that amend 15 CFR 744 Supplement No. 4. This search returns those rules, newest first, with title (Revisions to / Removal From the Entity List), effective date, docket and RIN, and links to federalregister.gov and the PDF that names the parties.

Tool input

{
  "search": "entity list",
  "agency": "BIS",
  "documentType": "RULE",
  "since": "2026-01-01",
  "maxResults": 20
}
