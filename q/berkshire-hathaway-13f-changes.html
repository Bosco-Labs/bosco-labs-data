What did Berkshire Hathaway buy and sell last quarter?

Berkshire Hathaway's holdings from its latest Form 13F-HR, each with shares, value, portfolio share and the change against the previous quarter.

Answered bySEC 13F Holdings API: fund & ETF holdings, 13D/13G, Form 144
Price$0.0018 per row, plus $0.01 per "who holds this stock" search (13F or N-PORT data set)
StatusOn Apify Store

Mode holdings13f reads the filer's latest Form 13F-HR, the quarterly list of US equity holdings that institutional managers above $100 million must file. Each row is one holding with issuer_name, cusip, ticker, shares, value_usd and portfolio_pct, and the change against the previous quarter (previous_shares, shares_change, shares_change_pct and a change label such as increased). Each row links the 13F filing it comes from.

Tool input

{
  "mode": "holdings13f",
  "filer": "Berkshire Hathaway",
  "maxResults": 50
}

Call the Apify API

Runs the Actor and returns the rows in one request, billed to your Apify account ($0.0018 per row, plus $0.01 per "who holds this stock" search (13F or N-PORT data set)).

curl https://api.apify.com/v2/acts/bosco_labs~sec-ownership/run-sync-get-dataset-items \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode": "holdings13f", "filer": "Berkshire Hathaway", "maxResults": 50}'
