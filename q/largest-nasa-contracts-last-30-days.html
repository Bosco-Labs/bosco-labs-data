Tools › Questions › US Federal Awards API

What were the largest NASA contracts in the last 30 days?

Answered byUS Federal Awards API: contracts & grants, all agencies
Price$0.004 per award row
StatusComing soon to the Store

agencies accepts common names such as NASA for the awarding agency; an empty dateFrom means the last 30 days. With the default sortBy amount, the biggest contract actions in the window come first. Each row names the recipient and its parent company, the amount, the award description, the place of performance and links to USAspending.gov.

Tool input

{
  "agencies": [
    "NASA"
  ]
}

Call the Apify API

Runs the Actor and returns the rows in one request, billed to your Apify account ($0.004 per award row). It works once the Actor is live on the Apify Store.

curl https://api.apify.com/v2/acts/bosco_labs~us-federal-awards/run-sync-get-dataset-items \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"agencies": ["NASA"]}'

Bosco Labs HTTP API (beta): same input and rows, $0.004 per award row from prepaid credits. Get a key with a $0.50 free trial.

  -H "Authorization: Bearer $BOSCO_API_KEY" \

  -d '{"agencies": ["NASA"]}'
