Tools › Questions › EU Public Tenders & Contract Awards API (TED procurement)

Find open IT tenders above 1 million euros in Germany and the Netherlands and list their deadlines.

Answered byEU Public Tenders & Contract Awards API (TED procurement)
Price$0.002 per notice
StatusOn Apify Store

The Actor queries TED, the EU's official journal for public procurement. CPV code 72 covers IT services; a prefix matches every code under it. The default notice type is contract_notice (open calls). Each row has notice_id, title, buyer_name and buyer_country, deadline, estimated_value and currency, cpv_codes and a ted_url to the notice. With publishedFrom left empty it searches notices published in the last 7 days. minValueEur uses TED's total value of the notice; notices without a value, or stated in another currency, are left out when it is set.

Tool input

{
  "countries": [
    "DE",
    "NL"
  ],
  "cpvCodes": [
    "72"
  ],
  "minValueEur": 1000000
}

Call the Apify API

Runs the Actor and returns the rows in one request, billed to your Apify account ($0.002 per notice).

curl https://api.apify.com/v2/acts/bosco_labs~eu-tenders/run-sync-get-dataset-items \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"countries": ["DE", "NL"], "cpvCodes": ["72"], "minValueEur": 1000000}'
