Did any Tesla insiders buy shares in the last 90 days?

Answered bySEC Insider Trading API (Form 4): stock transactions since 2006
Price$0.0018 per transaction row and $0.02 per cluster signal
StatusOn Apify Store

Transaction code P is an open-market purchase on SEC Form 4, so this input returns only real buys by Tesla directors, officers and 10% owners filed in the last 90 days, and leaves out grants, option exercises and tax withholding. Each row has the insider_name, insider_roles, transaction_date, shares, price and value_usd, the shares_owned_after the trade, and a filing_url to the Form 4 on EDGAR. An empty result means no insider bought on the open market in that window, which is itself the answer.

Tool input

{
  "tickers": [
    "TSLA"
  ],
  "transactionCodes": [
    "P"
  ],
  "lookbackDays": 90,
  "includeClusterSignals": false,
  "maxResults": 50
}
