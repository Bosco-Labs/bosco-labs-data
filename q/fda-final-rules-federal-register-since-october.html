Which final rules has the FDA published in the Federal Register since October 2026?

Answered byUS Federal Rules API: CFR text as of a date + Federal Register
Price$0.005 per section, $0.002 per document
StatusOn Apify Store

The Federal Register lists every FDA final rule by publication date; this input returns them newest first with title, action, abstract, effective_on, the CFR parts they change (cfr_references), docket ids and links to federalregister.gov and the govinfo PDF. A warning says how many documents match in total, so you know when to narrow or page with since.

Tool input

{
  "agency": "FDA",
  "documentType": "RULE",
  "since": "2026-10-01",
  "maxResults": 20
}

Ask it from an AI agent (MCP)

Add the Apify MCP server with this tool to your MCP client (Claude, Cursor, VS Code, ...); it signs you in with OAuth or Authorization: Bearer <APIFY_TOKEN>.

https://mcp.apify.com?tools=bosco_labs/us-federal-rules

Then ask:

Use the bosco_labs/us-federal-rules tool to answer: Which final rules has the FDA published in the Federal Register since October 2026?

Call the Apify API

Runs the Actor and returns the rows in one request, billed to your Apify account ($0.005 per section, $0.002 per document).

curl https://api.apify.com/v2/acts/bosco_labs~us-federal-rules/run-sync-get-dataset-items \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"agency": "FDA", "documentType": "RULE", "since": "2026-10-01", "maxResults": 20}'

Call the Bosco Labs HTTP API

Bosco Labs HTTP API (beta): same input and rows, $0.001 per unit: a CFR section with text = 5 units ($0.005), a Federal Register document = 2 ($0.002); rows without text are free from prepaid credits. Get a key with a $0.50 free trial, or send the same call without a key and pay per call in USDC via x402 (no account).

curl https://api.boscolabs.dev/v1/us-federal-rules \
  -H "Authorization: Bearer $BOSCO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"agency": "FDA", "documentType": "RULE", "since": "2026-10-01", "maxResults": 20}'
