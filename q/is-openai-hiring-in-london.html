Is OpenAI hiring in London, and for which roles?

Answered byCompany Hiring Signals API: open roles, departments, locations
Price$0.005 per company found plus $0.001 per job row
StatusComing soon to the Store

Yes. OpenAI's own job board (Ashby) lists roles located in London, mainly in Go To Market and Applied AI. The summary row counts total_open_roles and matching_roles by department and country; each job row has title, department, team, location, workplace type, posted_at and a link to the posting.

Tool input

{
  "companies": [
    "openai.com"
  ],
  "locations": [
    "London"
  ],
  "maxJobsPerCompany": 20
}

Ask it from an AI agent (MCP)

Add the Apify MCP server with this tool to your MCP client (Claude, Cursor, VS Code, ...); it signs you in with OAuth or Authorization: Bearer <APIFY_TOKEN>. It works once the Actor is live on the Apify Store.

https://mcp.apify.com?tools=bosco_labs/company-hiring-signals

Then ask:

Use the bosco_labs/company-hiring-signals tool to answer: Is OpenAI hiring in London, and for which roles?

Call the Apify API

Runs the Actor and returns the rows in one request, billed to your Apify account ($0.005 per company found plus $0.001 per job row). It works once the Actor is live on the Apify Store.

curl https://api.apify.com/v2/acts/bosco_labs~company-hiring-signals/run-sync-get-dataset-items \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"companies": ["openai.com"], "locations": ["London"], "maxJobsPerCompany": 20}'

Call the Bosco Labs HTTP API

Bosco Labs HTTP API (beta): same input and rows, $0.001 per unit: a company summary = 5 units ($0.005), a job row = 1 ($0.001); companies without a public job board are free from prepaid credits. Get a key with a $0.50 free trial, or send the same call without a key and pay per call in USDC via x402 (no account).

curl https://api.boscolabs.dev/v1/company-hiring-signals \
  -H "Authorization: Bearer $BOSCO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"companies": ["openai.com"], "locations": ["London"], "maxJobsPerCompany": 20}'
