When did Nvidia release its last four quarterly results, and was it before or after the market closed?

Answered bySEC EDGAR Filings API: 8-K, 10-K, 10-Q feed since 1994
Price$0.001 per filing
StatusOn Apify Store

earningsReleasesOnly keeps the 8-K filings with Item 2.02 (results of operations), which is how US companies file their earnings release. accepted_at is the SEC acceptance time and market_timing says whether that was before the open, during the session or after the close in New York. Each row links the filing index and its primary document (filing_index_url, primary_document_url), not the text itself.

Tool input

{
  "tickers": [
    "NVDA"
  ],
  "earningsReleasesOnly": true,
  "maxResults": 4
}

Ask it from an AI agent (MCP)

Add the Apify MCP server with this tool to your MCP client (Claude, Cursor, VS Code, ...); it signs you in with OAuth or Authorization: Bearer <APIFY_TOKEN>.

https://mcp.apify.com?tools=bosco_labs/sec-filings-feed

Then ask:

Use the bosco_labs/sec-filings-feed tool to answer: When did Nvidia release its last four quarterly results, and was it before or after the market closed?

Call the Apify API

Runs the Actor and returns the rows in one request, billed to your Apify account ($0.001 per filing).

curl https://api.apify.com/v2/acts/bosco_labs~sec-filings-feed/run-sync-get-dataset-items \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tickers": ["NVDA"], "earningsReleasesOnly": true, "maxResults": 4}'

Call the Bosco Labs HTTP API

Bosco Labs HTTP API (beta): same input and rows, $0.001 per filing from prepaid credits. Get a key with a $0.50 free trial, or send the same call without a key and pay per call in USDC via x402 (no account).

curl https://api.boscolabs.dev/v1/sec-filings-feed \
  -H "Authorization: Bearer $BOSCO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"tickers": ["NVDA"], "earningsReleasesOnly": true, "maxResults": 4}'
