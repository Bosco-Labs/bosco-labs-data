Before we accept a USDT payment, is wallet 0x7FF9cFad3877F21d41Da833E2F775dB0569eE3D9 on a sanctions list?

Answered bySanctions Screening API: OFAC, UK, EU, UN & US lists
Price$0.01 per name or wallet address screened
StatusOn Apify Store

The address is matched exactly (EVM addresses ignore upper and lower case) against every wallet address the loaded lists publish; today OFAC SDN publishes them. A listed address returns the listed entity, its programs, the listing date and a link to the OFAC entry; an unlisted one returns match_found false with the lists and dates it was checked against. It is a list lookup, not blockchain analytics: funds that passed through a listed wallet are not traced.

Tool input

{
  "addresses": [
    "0x7FF9cFad3877F21d41Da833E2F775dB0569eE3D9"
  ]
}

Add the Apify MCP server with this tool to your MCP client (Claude, Cursor, VS Code, ...); it signs you in with OAuth or Authorization: Bearer <APIFY_TOKEN>.

https://mcp.apify.com?tools=bosco_labs/sanctions-screening

Then ask:

Use the bosco_labs/sanctions-screening tool to answer: Before we accept a USDT payment, is wallet 0x7FF9cFad3877F21d41Da833E2F775dB0569eE3D9 on a sanctions list?

Call the Apify API

Runs the Actor and returns the rows in one request, billed to your Apify account ($0.01 per name or wallet address screened).

curl https://api.apify.com/v2/acts/bosco_labs~sanctions-screening/run-sync-get-dataset-items \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"addresses": ["0x7FF9cFad3877F21d41Da833E2F775dB0569eE3D9"]}'

Call the Bosco Labs HTTP API

Bosco Labs HTTP API (beta): same input and rows, $0.01 per name or wallet address screened (an address no list could be checked against is free) from prepaid credits. Get a key with a $0.50 free trial, or send the same call without a key and pay per call in USDC via x402 (no account).

curl https://api.boscolabs.dev/v1/sanctions-screening \
  -H "Authorization: Bearer $BOSCO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"addresses": ["0x7FF9cFad3877F21d41Da833E2F775dB0569eE3D9"]}'
