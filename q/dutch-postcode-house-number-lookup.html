Which address and building are at postcode 3011AD, house number 40?

Answered byDutch Address Lookup API: BAG postcode, geocode & building data
Price$0.002 per resolved address
StatusComing soon to the Store

A postcode plus house number is the exact way to address a Dutch property, so the match needs no fuzzy search. The row returns the street and city, building data from the BAG (year of construction, use, floor area) and coordinates. Add houseNumberAddition for flats such as 40-A.

Tool input

{
  "postcode": "3011AD",
  "houseNumber": 40
}

Ask it from an AI agent (MCP)

Add the Apify MCP server with this tool to your MCP client (Claude, Cursor, VS Code, ...); it signs you in with OAuth or Authorization: Bearer <APIFY_TOKEN>. It works once the Actor is live on the Apify Store.

https://mcp.apify.com?tools=bosco_labs/dutch-address-lookup

Then ask:

Use the bosco_labs/dutch-address-lookup tool to answer: Which address and building are at postcode 3011AD, house number 40?

Call the Apify API

Runs the Actor and returns the rows in one request, billed to your Apify account ($0.002 per resolved address). It works once the Actor is live on the Apify Store.

curl https://api.apify.com/v2/acts/bosco_labs~dutch-address-lookup/run-sync-get-dataset-items \
  -H "Authorization: Bearer $APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"postcode": "3011AD", "houseNumber": 40}'
