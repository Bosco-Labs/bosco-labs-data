Sanctions Screening API: OFAC, UK, EU & US export lists

Every answer says which lists were checked and how current they were, and every match links to its official source. Input fields

FieldTypeMeaning
namesarray (required)Company, vessel or person names to check, one per entry, as plain text, e.g. ["Sovcomflot", "Novo Nordisk A/S", "Vladimir Putin"]. Legal forms (Ltd, LLC, GmbH, PJSC), accents, punctuation and word order are ignored. 1-200 names; each name gives one result row and one charge; repeats are screened once. Required.
countrystringCountry of the party you are screening, as an ISO 3166 alpha-2 code or English name, e.g. "RU" or "Russia". It never hides a match: listings that name other countries move to the end and get country_match false. Empty = no country ranking.
entityTypestringOnly return listings of this type, e.g. "organization". Default "any". Listings whose type the list does not state (the US Commerce and State lists) are always kept.
minScoreintegerLowest similarity score (0-100) that counts as a match, e.g. 85 (default). 100 = same name after normalisation; 90-99 = small spelling differences or the name inside a longer listed name; lower values find more variants and more false positives. Range 50-100.
listsarrayWhich lists to check, any of "ofac_sdn", "ofac_consolidated", "us_csl", "uk", "eu", e.g. ["ofac_sdn", "uk"]. Default (or empty) = all five. The price is the same for any number of lists.

Sources, licence and limits

Is this legal advice or a compliance decision? No. It is a screening aid. Fuzzy name matching produces false positives (a namesake) and can miss a party listed under a spelling or script it doesn't recognise. Review every match against the official entry (source_url) before acting, and use your own judgement or counsel for decisions. Only the official publications are authoritative (for the EU, the Official Journal).

eu EU Consolidated Financial Sanctions ListEuropean Commission6,269

The CSL's Treasury sub-lists are skipped because the same entries come from OFAC directly.

What is not covered? The UN Security Council list is not used directly (its terms don't allow redistribution), but UN designations are largely included in the UK and EU lists. National lists of other countries, PEPs (politically exposed persons), adverse media, ownership (the OFAC 50% rule: companies owned by listed parties are often not listed themselves) and EU sectoral or vessel annexes outside the financial sanctions list are not covered.

How fresh is it? Each run uses the lists as published at most 1 hour earlier; older copies are downloaded again. lists_checked shows each list's own publish date. Agencies publish on their own schedule (OFAC and the CSL often daily, the UK and EU when designations change).

Why is listing_date null for OFAC? OFAC's standard XML doesn't include designation dates (only its 110 MB "enhanced" file does). Check the OFAC entry page in source_url.

Personal data? The lists name individuals. This Actor serves only per-name screening results (at most 5 listings per name, no bulk export) for sanctions compliance, and keeps only the fields needed to confirm or rule out a match. See LEGAL.md.
