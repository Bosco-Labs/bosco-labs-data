How to call

  • Apify API (synchronous): POST https://api.apify.com/v2/acts/bosco_labs~<actor>/run-sync-get-dataset-items with header Authorization: Bearer <APIFY_TOKEN> and the Actor input as the JSON body; the response is the dataset items.
  • Apify hosted MCP server: add https://mcp.apify.com?tools=bosco_labs/<actor> to your MCP client (Claude, Cursor, VS Code, ...). It loads the Actor as a tool plus get-actor-run and get-dataset-items, and signs you in with OAuth or Authorization: Bearer <APIFY_TOKEN>. On the default server (https://mcp.apify.com) agents can also find the Actors with search-actors and run them with call-actor.
  • Pricing: pay per event, billed to your own Apify account: you pay for rows delivered at the prices listed per Actor, and runs stop at your max charge limit.
  • Bosco Labs HTTP API: POST https://api.boscolabs.dev/v1/<tool> with Authorization: Bearer <key> for 8 fast lookups (same input and rows as the Actors), prepaid credits, $0.50 free trial; remote MCP at https://api.boscolabs.dev/mcp. Keys, prices and limits: https://boscolabs.dev/api.html
  • Contact: support@boscolabs.dev (questions, data issues, custom data requests).
  • Bosco Labs MCP server: bosco-labs-data-mcp on PyPI (https://pypi.org/project/bosco-labs-data-mcp/) and the official MCP Registry (io.github.PB7-debug/bosco-labs-data): one MCP server for all data Actors. Run it with uvx bosco-labs-data-mcp and set APIFY_TOKEN; source in https://github.com/PB7-debug/bosco-labs-data/tree/main/mcp.
