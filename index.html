Coverage, country by country

What one counterparty check reads in each country. Sanctions screening of the company, the LEI and IBANs work for every country, VAT numbers for the whole EU.

CountryWhat one check reads from the national sources
UKStatus: Companies House; insolvency: The Gazette; screened against the sanctions lists: directors and owners (PSCs)
PolandStatus: KRS; insolvency: KRS; screened against the sanctions lists: board (names the register shows in full)
NorwayStatus: Brønnøysund; insolvency: register status (bankrupt, winding up); screened against the sanctions lists: CEO and board
FranceStatus: Sirene; insolvency: BODACC; screened against the sanctions lists: directors (RNE)
Finland, EstoniaStatus: national register; insolvency: register status
IrelandStatus: Companies Registration Office (CRO) open data; insolvency: CRO status (liquidation, examinership, administration)
Czech RepublicStatus: ARES; insolvency: ARES status: in liquidation, or the Insolvency Register holds the company
LatviaStatus: Enterprise Register open data; insolvency: the register's insolvency and liquidation open data

More registers are being added. If you need a country that is not here, tell us: requests decide the order. The official route per country: company registers by country.

Call it from your stack

curl

curl https://api.boscolabs.dev/v1/counterparty-check \
  -H "Authorization: Bearer $BOSCO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "Carillion plc", "country": "GB"}'

Python

import os, requests

r = requests.post(
    "https://api.boscolabs.dev/v1/counterparty-check",
    headers={"Authorization": "Bearer " + os.environ["BOSCO_API_KEY"]},
    json={"query": "Carillion plc", "country": "GB"},
)
for check in r.json()["rows"][0]["checks"]:
    print(check["status"], check["check"], check["source_url"])

How to call

  • Apify API (synchronous): POST https://api.apify.com/v2/acts/bosco_labs~<actor>/run-sync-get-dataset-items with header Authorization: Bearer <APIFY_TOKEN> and the Actor input as the JSON body; the response is the dataset items.
  • Apify hosted MCP server: add https://mcp.apify.com?tools=bosco_labs/<actor> to your MCP client (Claude, Cursor, VS Code, ...). It loads the Actor as a tool plus get-actor-run and get-dataset-items, and signs you in with OAuth or Authorization: Bearer <APIFY_TOKEN>. On the default server (https://mcp.apify.com) agents can also find the Actors with search-actors and run them with call-actor.
  • Pricing: pay per event, billed to your own Apify account: you pay for rows delivered at the prices listed per Actor, and runs stop at your max charge limit.
  • Bosco Labs HTTP API: POST https://api.boscolabs.dev/v1/<tool> with Authorization: Bearer <key> for every tool listed with an API price (same input and rows as the Actors), prepaid credits, $5 free trial, or no key and pay per call in USDC via x402; remote MCP at https://api.boscolabs.dev/mcp. Keys, prices and limits: https://boscolabs.dev/api.html
  • Contact: support@boscolabs.dev (questions, data issues, custom data requests).
  • Bosco Labs MCP server: bosco-labs-data-mcp on PyPI (https://pypi.org/project/bosco-labs-data-mcp/) and the official MCP Registry (io.github.Bosco-Labs/bosco-labs-data): one MCP server for 7 of the data Actors (company-accounts, dod-contract-awards, esef-annual-reports, eu-tenders, sec-filings-feed, sec-insider-trades, us-house-trades) plus free LEI and SEC company lookups.
