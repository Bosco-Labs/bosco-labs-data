Check a Finnish company by API: PRH open data

PRH Trade Register (YTJ) · read from the national register · checked 11 November 2026

The official route

The Finnish Patent and Registration Office (PRH) has an open data service with two APIs. Neither needs a key.

  • YTJ API v3, https://avoindata.prh.fi/opendata-ytj-api/v3/companies: lookup by Business ID and name search. It returns name, legal form, status, registration date, address, TOL industry code and website.
  • XBRL API v3, https://avoindata.prh.fi/opendata-xbrl-api/v3/financials: financial statements that were filed digitally.

Both API specs name the licence as CC BY 4.0. PRH's service page asks you to mention the original source. It also says services built on the data may not use the PRH or Finnish Business Information System logos or copy their layout. No rate limit is published, though the specs list a 429 response.

Where it gets hard

  • Accounts are thin. PRH says you can only access statements filed in iXBRL and that they are "about 5 per cent of all financial statements". The rest are paper or PDF and not open data.
  • The digital statements arrive as XML with codes from PRH's SBR taxonomy. You map the codes to revenue, equity and so on yourself.
  • The YTJ API holds no board members. PRH's page also says details of private traders and companies' e-mail addresses and phone numbers are not available.
  • We read no separate insolvency source for Finland, so a bankruptcy shows only through the register status.

One call

{"query": "Nokia Oyj", "country": "FI"}

Use it as the body of POST https://api.boscolabs.dev/v1/counterparty-check. With the Business ID (0112038-9) as the query there is no name matching at all.
