Google Sheets Export: send any Apify dataset to a spreadsheet

Export any Apify dataset to Google Sheets: replace a tab or append rows, with nested fields as columns and your header kept.

Writes with your own Google service account key (the sheet shared with it as Editor) and retries Google rate limits. Use to send scraper results to a spreadsheet.

Run it on Apify Store →

What you get

The run writes no dataset rows. Its key-value store gets an OUTPUT record with spreadsheetUrl, sheetName, rowsWritten and columns. Nested objects become parent.child columns, arrays are written as JSON text, and values are never written as formulas.

Coverage

Any Apify dataset, written with your own Google service account (the sheet shared with it as Editor). Google allows 10 million cells per spreadsheet; rows are sent in batches of up to 5,000 rows or 2 MB.

Price

Pricing (pay per event): $0.00015 per row exported ($0.15 per 1,000 rows). No start fee; the run stops at your max charge limit.

Example input

{
  "datasetId": "aBcD1234efGH5678i",
  "spreadsheetId": "1AbCdEfGhIjKlMnOpQrStUvWxYz0123456789",
  "sheetName": "Leads",
  "mode": "append",
  "serviceAccountJson": "{ \"type\": \"service_account\", ... }",
  "fields": ["name", "address.city", "phone", "website"]
}

Example output

{"spreadsheetUrl": "https://docs.google.com/spreadsheets/d/1AbC...", "sheetName": "Leads", "rowsWritten": 1250, "columns": ["name", "address.city", "phone", "website"]}

Input fields

FieldTypeMeaning
datasetIdstring (required)Apify dataset ID to export, e.g. "aBcD1234efGH5678i": usually the defaultDatasetId of a scraper run (Storage tab).
spreadsheetIdstring (required)Google spreadsheet ID: the part between /d/ and /edit in the sheet URL docs.google.com/spreadsheets/d/<ID>/edit, e.g. "1AbCdEfGhIjKlMnOpQrStUvWxYz0123456789".
sheetNamestringName of the tab to write to, e.g. "Leads". Created if it doesn't exist. Leave empty to use the first tab (whatever it is called, e.g. "Sheet1" or "Blad1").
modestring"replace" (default) clears the tab's values and writes the dataset; "append" adds rows below the existing data, keeps your header and adds any new columns on the right.
serviceAccountJsonstring (required)Full contents of a Google service account JSON key file (secret input, stored encrypted). Share the spreadsheet with that account's client_email as Editor first. See the README for the 2-minute setup.
fieldsarrayColumns to export, in this order; nested fields use dots, e.g. ["name", "address.city", "phone"]. Empty = all fields.

Use with AI agents

Add this URL to your MCP client (Claude, Cursor, VS Code, ...) to load the Actor as a tool through the Apify hosted MCP server. It signs you in with OAuth or accepts Authorization: Bearer <APIFY_TOKEN>.

https://mcp.apify.com?tools=bosco_labs/sheets-export

Example prompt: “"Put the results of my last Google Maps run into the 'Leads' tab of my spreadsheet, only name, phone and website."” The agent passes:

{"datasetId": "<dataset ID>", "spreadsheetId": "<spreadsheet ID>", "sheetName": "Leads", "mode": "append", "serviceAccountJson": "<service account JSON key>", "fields": ["title", "phone", "website"]}

the run writes no dataset rows; its OUTPUT record in the key-value store holds spreadsheetUrl, sheetName, rowsWritten and columns, so the agent can link the sheet. serviceAccountJson is required, so the key passes through the agent's tool call: use a service account that is shared only on the sheets the agent may write to.

Or call the Apify API: POST https://api.apify.com/v2/acts/bosco_labs~sheets-export/run-sync-get-dataset-items with the input as JSON body. Cost: $0.00015 per row exported.
